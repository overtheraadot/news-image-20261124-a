## How it works

`render.py` draws `entry.png` locally with Pillow (kept in the repo so the
drawing is fully reproducible). `main.py` — the graded program, standard
library only — copies the committed `entry.png` to `$MAKEFUN_OUTPUT_DIR`
(default `/output`), so the sandbox run needs no network and is
byte-for-byte deterministic.
